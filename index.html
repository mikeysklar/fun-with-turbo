Fun with Turbo

Compiled acceleration for CircuitPython. Same board, same Python, a lot faster. In each video the top half is stock CircuitPython and the bottom half is Turbo.

Real-time text to speech

A Klatt speech synthesizer on the Adafruit Fruit Jam, reading the opening of Alice in Wonderland as the text comes in. The audio kernels are written in Viper and as C native modules, with measured speedups for each.

mikeysklar/klatt-tts-fruitjam

Concept and tools

turbo

Turbo firmware builds, the on-board shim, and the turbo CLI.

 turbo-cli

Host CLI that compiles CircuitPython modules to native .mpy with the official mpy-cross.

Turbo on the web

An early prototype of Turbo as a web page. It reads your code.py, shows which functions are worth making fast, compiles them in the browser, and installs the result on the connected board.
